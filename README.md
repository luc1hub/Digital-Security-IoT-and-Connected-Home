## ☑️ Checklist de Segurança Rápido para IoT
Antes de instalar qualquer dispositivo inteligente em sua rede, certifique-se de seguir estes passos:
- [ ] **Trocar a senha padrão:** Substituir credenciais de fábrica (`admin/admin`, `123456`) por senhas fortes e únicas.
- [ ] **Isolar a rede:** Conectar dispositivos IoT em uma rede Wi-Fi separada (rede de convidados / VLAN).
- [ ] **Verificar o fabricante:** Utilizar marcas confiáveis que disponibilizem atualizações de segurança regulares.
- [ ] **Desativar recursos desnecessários:** Desligar acessos remotos externos caso não sejam estritamente necessários.
- [ ] **Atualizar o Firmware:** Manter o sistema do roteador e dos aparelhos sempre na versão mais recente.
